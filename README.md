# The Byte Weaver

Webカメラを用いたハンドトラッキングにより、ユーザーの指の曲げ伸ばし（親指との接触）を7ビットのバイナリデータとして読み取り、ASCII文字をOSレベルで入力する仮想タイピングアプリケーションです。
技育camp　2026 vol.1 最優勝作品です
## 機能

- **7ビットバイナリ入力**: 両手の指の接触状態から7ビットのバイナリデータを読み取り
- **ASCII文字入力**: 読み取ったバイナリデータをASCII文字に変換し、OSレベルで自動入力
- **リアルタイムビジュアライゼーション**: カメラ映像とASCIIコード表を並べて表示
- **動的正規化**: 手のサイズに応じた相対距離で接触判定を行い、カメラ距離による誤差を軽減

## 必要な環境

- Python 3.7以上
- Webカメラ
- Windows/macOS/Linux

## インストール

1. リポジトリをクローンまたはダウンロード
2. 仮想環境を作成（推奨）:
   ```bash
   python -m venv venv
   ```
3. 仮想環境を有効化:
   - Windows: `venv\Scripts\activate`
   - macOS/Linux: `source venv/bin/activate`
4. 依存パッケージをインストール:
   ```bash
   pip install -r requirements.txt
   ```

## 使い方

1. アプリケーションを起動:
   ```bash
   python byte_weaver.py
   ```
2. カメラの前に両手を出し、指の接触状態で7ビットのバイナリデータを入力
3. 左手小指を親指に接触させると、現在のバイナリ値に対応するASCII文字が入力されます
4. 'q'キーで終了

## ビットマッピング

- **Bit 1 (LSB)**: 右手 小指 (Tip 20)
- **Bit 2**: 右手 薬指 (Tip 16)
- **Bit 3**: 右手 中指 (Tip 12)
- **Bit 4**: 右手 人差し指 (Tip 8)
- **Bit 5**: 左手 人差し指 (Tip 8)
- **Bit 6**: 左手 中指 (Tip 12)
- **Bit 7 (MSB)**: 左手 薬指 (Tip 16)

各指が親指と接触している場合、そのビットは1（ON）になります。

## トリガー

左手小指を親指に接触させると、現在の7ビット値に対応するASCII文字が入力されます（エッジトリガー）。

## 表示可能な文字

ASCII値32-126（表示可能な文字）のみが入力されます。制御文字（バックスペース: 8、エンター: 13）も特別に処理されます。
