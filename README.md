# The Byte Weaver

Webカメラのハンドトラッキングで指の曲げ伸ばし（親指との接触）を **7ビットのバイナリ** として読み取り、対応する ASCII 文字を **OSレベルで入力** する仮想タイピングアプリ。

## 概要

両手の指の接触状態を 7 ビット（0〜127）として解釈し、ASCII文字に変換してキーボード入力をエミュレートします。「指でバイナリを打つ」という発想を実際に動くアプリに落とし込んだ、コンセプト先行のプロジェクトです。

## 主な機能

- **7ビットバイナリ入力**: 両手の指の接触状態から7ビットを読み取り
- **ASCII文字入力**: バイナリ値をASCII文字に変換し、OSレベルで自動入力
- **リアルタイム可視化**: カメラ映像とASCIIコード表を並べて表示
- **動的正規化**: 手のサイズに応じた相対距離で接触判定し、カメラとの距離による誤差を軽減

## 工夫した点

- **動的正規化による接触判定**：絶対座標ではなく手のサイズ基準の相対距離を使うことで、カメラからの距離が変わっても安定して判定できるようにした。
- **エッジトリガー方式の確定入力**：左手小指のタッチを「入力確定」トリガーにすることで、誤連打を防ぎ意図したタイミングだけ入力されるようにした。
- 表示可能なASCII（32〜126）に加え、バックスペース(8)・エンター(13)も特別処理し、実用的なタイピングを可能にした。

## ビットマッピング

| ビット | 担当指 | ランドマーク |
|--------|--------|--------------|
| Bit 1 (LSB) | 右手 小指 | Tip 20 |
| Bit 2 | 右手 薬指 | Tip 16 |
| Bit 3 | 右手 中指 | Tip 12 |
| Bit 4 | 右手 人差し指 | Tip 8 |
| Bit 5 | 左手 人差し指 | Tip 8 |
| Bit 6 | 左手 中指 | Tip 12 |
| Bit 7 (MSB) | 左手 薬指 | Tip 16 |

各指が親指と接触している場合、そのビットが 1（ON）になります。**左手小指 + 親指**の接触で、現在の7ビット値に対応するASCII文字を確定入力します（エッジトリガー）。

## 使用技術

- **言語**: Python 3.7+
- **ハンドトラッキング**: Webカメラ + ハンドトラッキング（指ランドマーク検出）
- **対応OS**: Windows / macOS / Linux

## セットアップ

```bash
# 仮想環境（推奨）
python -m venv venv
# Windows: venv\Scripts\activate / macOS・Linux: source venv/bin/activate

pip install -r requirements.txt
python byte_weaver.py
```

カメラの前に両手を出し、指の接触で7ビットを入力 →  左手小指を親指に接触させて確定 → `q` で終了。
